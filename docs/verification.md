# Проверки от 27 сентября 2026 года

- Ruff: правила и форматирование прошли; mypy не нашёл ошибок в 16 модулях.
- pytest: 21 тест прошёл с отдельными PostgreSQL и RabbitMQ.
- Конкурентные смена статуса и назначение одной версии не теряют изменения.
- Одноразовый Telegram-код погашается один раз даже при конкурентных запросах;
  проверены срок действия, запрет группового чата и захвата чужой привязки.
- Повторы webhook создают одну заявку; изменение содержимого того же update_id даёт конфликт.
- Внутренние комментарии скрыты вместе с историей и не направляются клиенту.
- Конкурентный приём события создаёт одно задание на получателя.
- Проверены временная ошибка, retry_after, постоянная ошибка и исчерпание попыток.
- Просроченная задача подбирается повторно; старый worker не может сохранить результат.
- Завершённый получатель не отправляется повторно при обработке другого получателя.
- Настоящий RabbitMQ проверен на публикации outbox и переносе некорректного сообщения
  в карантинную очередь; подтверждение исходной доставки выполняется после записи в карантин.
- Ручной повтор разрешён администратору и записывает автора и причину в аудит.
- Сбой outbox откатывает создание заявки. Устаревшая привязка не используется для отправки.
- Миграция проверена на исторических данных отдельной временной БД:
  контрольная сумма старых полей сохранилась, версии получили значение 1,
  старые Telegram-привязки не стали автоматически подтверждёнными.
- Compose-стенд собран и запущен: API, PostgreSQL и RabbitMQ прошли healthcheck;
  оба worker работают. API использует UID 10001. `/health` вернул `200`.

Реальная отправка Telegram и регистрация внешнего webhook не выполнялись.
Ответы Telegram воспроизводятся контролируемым транспортом; проверка с живым
ботом требует собственных реквизитов и HTTPS-адреса. Нагрузочные пределы,
восстановление резервной копии и отказ целого кластера не проверялись.
Дубликат внешнего сообщения после неопределённого результата отправки остаётся возможным.

[GitHub Actions](https://github.com/dasferwer/helpflow/actions/workflows/ci.yml)
повторяет автоматические проверки для каждого опубликованного коммита.
